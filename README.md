# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

给手工地毯修复工作室使用的纹样与修复档案单页应用：记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序。页面包含纹样局部标记图、修复前后记录、材料色卡、工序进度和按产地筛选的档案列表。

## 业务规则

- **单页档案**：一屏录入产地、年代、结密度、材质、染色类型（植物染 / 化学染 / 混合染）、纹样备注。
- **破损与补线**：每处破损只绑定一种补线色号；多处破损共用同一补线批次时，耗用长度按批次合并。
- **整单扣减**：保存时用「全部在档地毯」重算每个色号的占用并与库存剩余长度比对；任一批次超量则**整次保存失败**，工序状态、色卡库存均保持原样，错误明细列在编辑面板顶部。
- **染色迁移冻结**：湿洗中登记染色迁移后，湿洗之后的工序冻结；补救工序「局部回色 → 冲洗确认」均完成后自动解除。冲洗必须在回色完成后才能确认。
- **同步视图**：修复前后记录、局部标记图（标记颜色取绑定色号）、材料色卡、工序进度、产地筛选共用同一份本地数据。
- **仅本地存储**：档案、照片（自动压缩为缩略图）、色卡、工序全部通过 `localStorage` 保存在当前浏览器，不含任何网络请求；首次打开自动写入 3 张演示档案与 6 个补线批次。

## 技术栈

React 19 + Vite + TypeScript（无 UI 框架，纯本地数据）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62009

```bash
npm run build   # tsc 类型检查 + vite 打包
```

## 代码结构

- `src/types.ts` — 领域模型、工序定义、冻结判定、耗用汇总
- `src/storage.ts` — localStorage 读写、补线库存整单校验、演示数据
- `src/components/CarpetEditor.tsx` — 单页档案、破损绑定、修复前后记录
- `src/components/MarkerMap.tsx` — 纹样局部标记图（可拖拽定点）
- `src/components/ProcessTimeline.tsx` — 工序进度与染色迁移冻结
- `src/components/ThreadPalette.tsx` — 材料色卡与补线批次库存
- `src/components/CarpetList.tsx` — 按产地筛选的档案列表
